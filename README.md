## 🧠 Overview

**GhostTerminal** is an interactive web-based fake operating system designed to simulate a hacker-style terminal experience.

It blends:

* command-line interaction
* visual effects
* psychological illusions
* embedded mini-games

At its core, GhostTerminal is not just a UI — it’s an **experience**.

---

## 🎮 Protocol 21 (MindTrap System)

Inside GhostTerminal lies **Protocol 21**, a hidden logic-based game.

### Rules:

* There are **21 encrypted nodes**
* Player and AI take turns
* Each turn: remove **1, 2, or 3 nodes**
* Whoever removes the **last node loses**

### Twist:

The system is designed to **outplay the user using mathematical strategy**, creating the illusion of intelligence.
